# Student Ranking and Result Analyzer

## 📌 Project Description
The **Student Ranking and Result Analyzer** is a Python-based desktop application developed as a mini project for the subject **Design and Analysis of Algorithms (DAA)**.

This application helps teachers manage student records, calculate results, generate rankings, and search for student details. It automatically calculates total marks, percentage, grades, and Pass/Fail status.

The project demonstrates the practical implementation of **Bubble Sort and Linear Search algorithms**.

## 🚀 Features
- Add new student records.
- Store student information in a JSON file.
- Calculate total marks and percentage automatically.
- Generate grades and Pass/Fail status.
- Rank students according to their percentage.
- Search students using roll number.
- Delete selected student records.
- Display all student rankings.
- Analyze algorithm execution time.
- Input validation for marks and duplicate roll numbers.

## ⚙️ Algorithms Implemented

**1. Bubble Sort**
- Used to arrange students in descending order according to percentage.
- Time Complexity: O(n²)

**2. Linear Search**
- Used to search for a student by roll number.
- Time Complexity: O(n)
